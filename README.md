# File Tagger

This is a small utility program that will allow users to "tag" files and folders in their filesystem.

The main purpose of this tool is to learn.

Please, do not rely on it for real use cases.

## Clone the project

To start working on this projet clone it with this command:

`git clone https://github.com/ndvo/file-tagger.git`

Then navigate into the `file-tagger` folder that will be created.

`cd file-tagger`
